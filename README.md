# Media Pembelajaran IPA - Interaktif

Projek ini adalah demo sederhana media pembelajaran IPA untuk usia 14-15 tahun.

Cara menjalankan:

1. Buka file `index.html` di peramban (double-click atau `Open File`).
2. Gunakan tombol "Berikutnya" dan "Sebelumnya" untuk membaca slide.
3. Tekan "Mulai Kuis" untuk mengerjakan kuis interaktif.

Catatan: tidak perlu server; halaman berjalan langsung di peramban.
